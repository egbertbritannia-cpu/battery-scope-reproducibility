# Permissions and attribution

No repository-wide software or document license has been assigned in this snapshot. Public visibility is not a grant of an MIT, Apache, Creative Commons, or other blanket license. Retain existing notices and obtain any additional permissions needed for reuse.

The implementation contains project research code and inherited project runtime components. It imports external libraries rather than redistributing their installations. Those libraries retain their own licenses. This release excludes the conference LaTeX style/template files because their redistribution terms were not established for this snapshot.

BatteryLife and the individual battery-data providers retain rights and terms for their datasets. Data are not mirrored here. Primary references and source attribution are listed in `docs/references.bib`. In particular, the underlying processed data are inherited from BatteryLife; this repository does not claim to introduce or own those measurements.

The source/seed metrics are research outputs for the reported analyses. Model checkpoint names, source names and seed identifiers are retained where required to interpret them. Author identity has not been inferred for citation metadata; add the agreed author list and a chosen license before representing this as a generally licensed software release.
